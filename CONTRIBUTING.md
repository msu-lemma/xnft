# Contributing Guidelines

## DCO Sign-off

All contributions to the repository must be signed using the Developer Certificate of Origin sign-off.

To add this sign-off to a commit automatically, use `git commit -s`.  This will automatically add the following trailer to your commit message:

```text
Signed-off-by: Your Name <name@example.com>
```

By applying this signature you certify that the commit adheres to the statements in the [Developer Certificate of Origin](DCO.txt).
